- 模式：审计 / 设计 / 实施 / 发行验收（待填）
- 目标、仓库基线commit、用户已有改动：待填

- 服务端和隔离环境权限：待填
- 原始/保护版产物摘要、构建ID与来源：待填
- 排除项、离线要求、兼容和性能预算、停止条件：待填

每个测试记录：ID、脱敏命令/参数、环境/版本、输入类别、预期、实际、退出码/状态、副作用和证据位置。动态分析记录授权目标/动作、创建的进程/文件及清理结果；清理失败不得隐藏。

覆盖率记录分母定义、自有模块总量、已测/已保护范围、排除项与未知区域。性能记录设备、样本、指标/分位数与预算，不以单次最快结果代表平均表现。

## 发布与回滚
1. 协议兼容矩阵、最低安全版本、灰度范围：待填。
2. 服务端先后顺序、签名基线/证书轮换、回退条件：待填。
3. 回滚版本/备份与操作：待填。回滚不得恢复已撤销密钥、无效许可证或已知鉴权漏洞。
4. 分别标注文档、实现、本地测试、构建、签名、部署、线上验证状态。
5. 未完成项列明阻塞证据、所需权限/工具/设备及下一步最小动作。

摘要句式：“已在【范围】完成【改动】，用【测试】验证【具体行为】。未验证【平台/线上/未知区域】；客户端控制仍可能被篡改，服务端授权继续独立生效。”
